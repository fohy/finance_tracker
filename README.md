# FinFlow — локальный учёт семейных финансов

Полноценное локальное веб-приложение для учёта доходов, расходов, инвестиций, целей и покупок. Данные хранятся в SQLite и никуда не отправляются.

## Что реализовано

- доходы, расходы и переводы на инвестиционный счёт;
- подробные стандартные категории, заметки и собственные категории;
- отдельные метрики по Саше и Насте;
- баланс на жизнь и инвестиционный баланс;
- автоматическое ежедневное начисление процентов на инвестиционный счёт;
- статистика по дню, неделе и месяцу;
- сравнение с предыдущим периодом;
- индекс правильности финансовых действий от 0 до 100;
- прогноз доходов, расходов, свободного остатка и инвестиций;
- список будущих покупок с безопасным темпом накоплений;
- финансовые цели и необходимая сумма накоплений в месяц;
- калькулятор будущей стоимости инвестиций;
- адаптивный интерфейс для компьютера, планшета и телефона;
- REST API, разделение роутов, сервисного слоя и работы с базой.

## Быстрый запуск — Windows

1. Установите Python 3.11 или новее.
2. Распакуйте архив.
3. Дважды нажмите `start_windows.bat`.
4. Откройте в браузере: `http://127.0.0.1:5000`

Или вручную:

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python app.py
```

## Быстрый запуск — macOS / Linux

```bash
chmod +x start_macos_linux.sh
./start_macos_linux.sh
```

Или вручную:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

После запуска откройте `http://127.0.0.1:5000`.

## База данных

Файл базы находится здесь:

```text
instance/finance.db
```

Для резервной копии достаточно остановить приложение и скопировать этот файл.

Новая база по умолчанию пустая: это безопаснее для настоящего семейного учёта.
Чтобы создать демонстрационную базу:

1. остановите приложение;
2. удалите `instance/finance.db`;
3. снова запустите приложение.

Чтобы явно создать пустую базу без демонстрационных операций:

macOS / Linux:

```bash
SEED_DEMO=0 python app.py
```

Windows PowerShell:

```powershell
$env:SEED_DEMO="0"
python app.py
```

При этом люди, категории, счета и базовые настройки всё равно будут созданы автоматически.

## Настройка процентов

Откройте раздел **Инвестиции**. Годовая ставка хранится у инвестиционного счёта в SQLite. При каждом открытии приложения система вычисляет количество дней после последнего начисления, капитализирует доход и добавляет отдельную операцию «Начисление процентов».

Стартовая ставка — 12,5% годовых. Её можно изменить через API или напрямую в SQLite:

```sql
UPDATE accounts
SET annual_rate = 15
WHERE kind = 'investment';
```

## Разработка и качество

Проект использует factory pattern, изолированную тестовую БД и отделяет HTTP-роуты
от правил изменения баланса (`finance/transaction_service.py`). Изменение баланса
напрямую через API запрещено: оно должно иметь операцию в журнале. Каждое создание
и удаление операции фиксируется в `audit_log`.

Для разработки установите дополнительные инструменты и запустите проверки:

```bash
python -m pip install -e '.[dev]'
make check
```

Перед открытием приложения в локальной сети задайте уникальный `SECRET_KEY` через
переменную окружения. Шаблон есть в `.env.example`; секреты и файл базы не коммитьте.

## Основные API-маршруты

- `GET /api/bootstrap` — справочники и счета;
- `GET /api/summary` — статистика, индекс и прогноз;
- `GET/POST /api/transactions` — операции;
- `DELETE /api/transactions/<id>` — удаление с откатом баланса;
- `GET/POST /api/purchases` — покупки;
- `GET/POST /api/goals` — цели;
- `GET /api/people-metrics` — отдельные метрики по людям;
- `GET/PUT /api/settings` — финансовые ориентиры.

## Важное

Это локальный финансовый трекер, а не банковская или бухгалтерская система. Перед серьёзными изменениями базы делайте копию `instance/finance.db`.
